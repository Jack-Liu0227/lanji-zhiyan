# v1.2.0 合入后「界面打不开」问题：症状 · 根因 · 修法

> 记于 2026-10-16。对应改动：`apps/desktop/web/index.html` 里 `zotBind()` 删掉一句死绑定（见提交信息）。
> 现象是**用户可感知的**：双击桌面快捷方式后窗口起来、标题正常、HTTP 200，但界面是个空壳。

---

## 1. 症状（看到的 vs 以为的）

| 观测 | 结果 |
|---|---|
| 双击快捷方式 | 进程起来了，窗口出现 |
| 窗口标题 | `览籍智研 · v<构建戳>` —— **正常**（所以标题不能当判据：它来自 `create_window(title=…)`，与页面渲染无关） |
| `curl 8765/` | 200，体积正常（485KB） |
| `GET /api/state` | 200，项目/助手/对话数据都在 |
| `python -m unittest discover -s tests -t .` | **114 项全绿** |
| 屏幕上 | **空壳**：深色底 + 空侧栏 + 空主区。用户的说法是「点进去打不开」 |

## 2. 根因

`apps/desktop/web/index.html` 的 `zotBind()` 在**顶层**直接执行：

```js
$("btnZotClose2").onclick = zotClose;      // 顶层执行，取到 null 即抛
```

而 `#btnZotClose2` 这个元素在 v1.2.0 的模态框重排里被删掉了（Zotero 弹窗的页脚「关闭」按钮），**引用没跟着删**。

- 顶层抛 `TypeError: Cannot set properties of null (setting 'onclick')`
  → 该行**之后**的所有初始化（`renderSidebar()` 等）**一行都不执行** → 侧栏/主界面不建立 → 空壳。
- 这是**功能性白屏**，不是语法错：`tests/test_web.py` 只把最大那块 `<script>` 抽出来跑 `node --check`，语法全过 → 测试全绿。

## 3. 定位手法（可复用）

1. 起带调试口的实例：`RW_DEBUG_CDP=9333 pythonw apps/desktop/server.py`（**同一时刻只能有一个实例**——WebView2 的 user data 目录独占）。
2. 连 CDP（`http://127.0.0.1:9333/json` → 取 `url` 含 `8765` 的 page target）→ `Page.reload{ignoreCache:true}` → 读四个数：
   - `(document.querySelector('#sidebar')?.innerHTML||'').length` —— 十步版正常 ≈ **3.7k**，**0 = 界面没建起来**
   - `document.querySelectorAll('.nav-item').length` —— 正常 **14**
   - `Runtime.exceptionThrown` 的 `lineNumber` —— 直接指到那一行
   - `Network.responseReceived` 里 ≥400 的请求（本次只有 `favicon.ico`，无害）
3. 静态预检（不起浏览器）：`node apps/desktop/web/ids.test.mjs` —— 把 `$("x")` / `getElementById("x")` 的引用跟全文件 `id="…"`（含 JS 模板串里拼出来的）比一遍，列出「引用了但页面里没有的 id」。已进 `tools\check.bat` 第 3 步。本次 4 条命中：
   - `btnZotClose2` —— **致命**（顶层、无兜底）
   - `mailNotifStack` / `prLangTo` / `prTranslateSource` —— 合入前就缺，代码里有 `?.` 或 `if(!x) return`，**静默退化不崩**（`mailNotifStack` 缺席 ⇒ 新邮件浮层一直没容器）
4. 判「是不是这轮合入弄坏的」：`git show <合入前那笔>:apps/desktop/web/index.html | grep -c 'id="btnZotClose2"'` —— 合入前 = 1（有），合入后 = 0（没了）。

## 4. 修法

**删掉那句死引用**，按这次重排的本意走（弹窗仍有标题栏 ✕ + 点遮罩关闭），并在注释里写明它为什么致命。
**不要**为了救这一句去把页脚按钮加回来 —— 那是把「改动的本意」和「死引用」倒过来迁就。

## 5. 以后怎么防（最低验收线）

**HTTP 200 / 窗口标题 / 单测全绿都不算「界面能用」**。收尾必须量上面第 3 条那两组数（侧栏长度 + nav 项数），或跑一次静态预检。
