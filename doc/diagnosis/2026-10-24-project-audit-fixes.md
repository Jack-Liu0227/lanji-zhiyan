# 项目复查问题修复

基于 `831c882` 的全项目复查发现 10 个可复现问题。本次修复覆盖数据写入、笔记索引、工作流交付、恢复及调度边界。

| 问题 | 修复行为 | 回归场景 |
| --- | --- | --- |
| 谱系图起稿失败仍覆盖旧稿 | 任一章节为空或生成失败时停止提交，保留原稿并标记失败；拒绝旧版缺失章节占位内容交付 | 全部空响应、部分章节失败、旧占位稿验收 |
| 同名 PDF 覆盖 | 每次下载使用独立文件名，保留可读标题 | 同名、标题截断碰撞、字符清理碰撞 |
| Zotero 错误匹配不同 DOI | DOI 精确匹配优先；双方 DOI 不同不能按标题匹配；多候选要求解决冲突 | 同名不同 DOI 保持独立、精确 DOI 优先、标题歧义；检索缓存也不合并不同 DOI |
| 删除项目残留可恢复任务 | 取消活动执行，清理异步任务、事件、尝试、调度和待办关联；旧孤立任务单独标记中断 | 删除后恢复、旧孤立任务不阻塞正常任务、定时任务迟到结果不再写回 |
| 笔记编辑删除与检索不同步 | 文件编辑同步旧笔记表及资产索引，删除归档资产并清理旧语义块；其他编辑入口沿用规范路径 | 新建、修改、单文件和目录删除、跨编辑入口、语义索引失效 |
| 写作恢复跳过审查定稿 | 持久化本次写作模式，恢复时沿原路线执行；兼容已有流水线检查点 | 在初稿落盘后模拟进程中断，恢复审查并写回定稿；旧检查点同样覆盖 |
| README 可冒充转换产物 | 交付只使用已登记且存在的非空导出资产，不使用浏览器文件列表 | README 与源稿不能验收；真实导出可验收，内容变化后失效，旧文件删除不阻断新产物 |
| 有并行任务仍提前验收 | 汇总异步任务、团队任务及关联调度的活动状态，活动任务优先于最后一条完成记录 | 慢任务尚未结束时，快任务完成也不能交付 |
| 手动调度重复执行 | 手动、自动、补跑共用按数据库和规则划分的执行锁；删除使用线程安全取消信号 | 手动与自动重叠只调用一次；完成后可以再次执行；真实执行循环的取消检查 |
| 团队取消立即重试丢失 | 记录待重试请求，旧线程退出后恢复排队；再次取消撤回待重试请求 | 取消后立即重试、重试后再次取消 |

完整回归同时暴露了工作流页面结束后的刷新竞争：运行记录过早移除，而输入框仍在异步重建。现在等历史消息及事件处理器恢复后再结束界面中的运行跟踪，并防止旧运行清理新运行。

新增行为测试位于 `tests/test_audit_regressions.py`。测试使用独立临时项目、临时数据库和受控模型/Zotero 响应；不依赖真实远端写入。已有浏览器测试使用真实 Edge 和本地 HTTP 服务。
