# 界面导航与截图

当前界面以项目工作区为研究入口。先在左侧选择页面，再在项目内切换工作视图。本文截图采集于 2026-10-28，使用独立演示项目；示例资料用于展示操作，不代表真实发表的论文或已完成的科研成果。

## 左侧导航

| 页面 | 用途 | 操作说明 |
| --- | --- | --- |
| 智研管家 | 跨项目讨论研究目标、查询进展和调度研究 | [项目与工作流](projects-and-workflows.md) |
| 专家 | 创建、编辑和启停研究专家 | [专家与团队](other-pages-data-and-help.md) |
| 团队 | 查看负责人、成员和团队研讨 | [专家与团队](other-pages-data-and-help.md) |
| 项目工作区 | 选择项目，进入对话、资料、任务与图流 | [项目与工作流](projects-and-workflows.md) |
| 任务与自动化 | 汇总所有项目的计划、实际执行与自动化，双击任务进入原对话 | [任务与日历](tasks-and-calendar.md) |
| 论文工具箱 | 图片、翻译、润色、引文、文稿和图表工具 | [对话与工具箱](conversations-and-toolbox.md) |
| 日历 | 查看日程、计划截止和待核查记录 | [任务与日历](tasks-and-calendar.md) |
| 知识库 | 浏览项目与授权知识源的关联 | [其他页面](other-pages-data-and-help.md) |
| 情报日报 | 阅读资讯、导入题录和管理订阅入口 | [RSS 与情报日报](other-pages-data-and-help.md) |
| 邮箱 | 配置科研邮箱、收信与写信 | [邮箱与消息连接](other-pages-data-and-help.md) |
| 设置 | 配置模型、权限、工具、技能、MCP、模板与连接 | [安装与首次配置](getting-started.md) |

顶部还有 To do、用量统计、论文工具箱快捷面板、命令搜索和快捷键帮助。项目切换和“＋ 新建项目”放在项目工作区顶部。

## 项目内四个主视图

| 主视图 | 常用操作 |
| --- | --- |
| 目标对话 | 创建课题会话，引用资料，调整模型、推理强度和工具权限，选择执行者 |
| 统一资料库 | 查看全部资料、目录与文件、文献论文、研究笔记和论文星图 |
| 任务与自动化 | 切换 To-do 计划、实时任务看板、自动化规则，查看交付与人工核查 |
| LangGraph 图流 | 选择模板、编辑节点与依赖、准备运行、查看固定版本与节点任务 |

“项目设置”提供项目信息、项目概况、资料索引、执行者与模式、团队与成员、专家管理等入口。它与四个工作视图共用当前项目。

### 目标对话

左侧是项目会话历史，中间是对话与执行轨迹，输入区保存本会话设置。引用文件时可以先预览，再返回对话继续讨论。

![目标对话与项目内执行者](../screenshots/project-workspace-chat.png)

### 统一资料库

左侧提供资料视图和目录导航。全部资料按用途筛选，打开文件后使用同一份项目原文件进行预览、编辑、引用或交接。

单独查看目录导航的布局可打开[目录与文件截图](../screenshots/project-workspace-files.png)。

![统一资料库](../screenshots/project-workspace-library.png)

### 任务与自动化

左侧一级入口默认汇总所有项目，可按项目筛选；项目内入口只展示当前项目，两处使用同一份记录。To-do 计划记录尚待安排的目标；实时任务看板显示真实执行状态；自动化规则保存持续触发的配置。双击任务直接进入所属项目的执行对话，查看产物与人工核查。

![实时任务看板](../screenshots/project-workspace-tasks.png)

### LangGraph 图流

画布显示节点和依赖，右侧显示所选节点的配置或本次运行内容。“准备 / 查看运行”打开运行设置；准备和开始执行是两个步骤。

![LangGraph 画布与节点配置](../screenshots/project-workspace-flow.png)

## 常用功能入口对照

| 想完成的操作 | 当前入口 |
| --- | --- |
| 新建、编辑项目 | 项目工作区顶部“＋ 新建项目”；“项目设置 → 编辑项目信息” |
| 管理项目文献与 PDF | 统一资料库 → 文献论文 (PDF) |
| 管理笔记与分类 | 统一资料库 → 研究笔记 (Markdown) |
| 浏览或交接文件 | 统一资料库 → 目录与文件；预览栏“交由专家/团队处理” |
| 查看计划或执行情况 | 任务与自动化 → To-do 计划 / 实时任务看板 |
| 设置周期研究 | 任务与自动化 → 自动化规则 |
| 配置或跟踪研究流程 | LangGraph 图流；全局模板在“设置 → 工作流”管理 |
| 管理提示词模板 | 论文工具箱右上角“管理模板” |
| 管理资讯订阅源 | 情报日报“订阅源设置”；或“设置 → RSS 订阅源” |
| 连接消息应用 | 设置 → 消息渠道；飞书支持对话，其他渠道提供消息推送 |

文献搜索、精读、翻译、写作和审阅通过专家、团队或图流节点组合使用。项目工作区统一保留研究资料、任务与交付入口。
