# 真边界 spike（2026-10-20）：把文件读写真正限制住，可行到哪一步

问题：能不能让「程序只能读写自己的 `data/` + 用户选过的项目文件夹」变成**内核强制**，而不是应用层自觉？
三轮实测，结论一句话：**写入边界能做到且不用管理员（Low IL）；读写全限的 AppContainer 从 Python 里起不来。**

## 一、受限令牌（restricted token + S-1-5-12）—— 死路

`CreateRestrictedToken` 加限制 SID `S-1-5-12` 后，`CreateProcessAsUser` **能起来**，但子进程立刻以
`0xC0000142`（STATUS_DLL_INIT_FAILED）退出：System32 的 ACL 只认 `Users/Everyone`，不认 RESTRICTED SID，
而给 `C:\Windows\System32` 加 ACE 需要管理员（实测 `icacls` 直接失败）。这条路对普通用户不可用。

## 二、AppContainer + SECURITY_CAPABILITIES —— 从 Python 起不来（假沙箱，最危险）

用 `STARTUPINFOEX` + `PROC_THREAD_ATTRIBUTE_SECURITY_CAPABILITIES` + `CreateProcess`，
`CreateAppContainerProfile` 拿到容器 SID，`UpdateProcThreadAttribute`/`CreateProcess` 都返回成功，
子进程也跑完了 —— 但**它根本没进容器**：

- 子进程里 `GetTokenInformation(TokenIsAppContainer=29)` → **0**
- `C:\Windows\System32\whoami.exe /groups` → **Mandatory Label\Medium**，无任何 AppContainer SID
- 反证：子进程把文件写进了桌面（`~/Desktop/ac_probe.txt`），证明完全没受限

也就是说：属性被静默忽略，**看起来成功、实际零隔离**。继续走这条要么用未文档化的
`CreateAppContainerToken`，要么写 C++ shim；而且容器里 **loopback 默认被禁**，
要让窗口连上自己的 `127.0.0.1:8765` 还得 `CheckNetIsolation LoopbackExempt`（需管理员）。

## 三、低完整性级别（Low IL）—— 可行，且正好是他要的那一半

复制当前令牌 → `SetTokenInformation(TokenIntegrityLevel, S-1-16-4096)` → `CreateProcessAsUser`
（普通用户就能起，实测成功）。把 `data/` 与项目目录 `icacls /setintegritylevel (OI)(CI)L` 标成 Low，
然后子进程自报：

| 动作 | 结果 |
|---|---|
| 写授权目录（已标 Low） | ✅ 写成功 |
| 写桌面 | ❌ Permission denied |
| 写 `C:\Windows\Temp` | ❌ Permission denied |
| 写用户目录根 | ❌ Permission denied |
| 读 `C:\Windows\win.ini` | ✅ 读成功（Low IL 不管读） |
| `xelatex --version` | ✅ rc=0 |
| `GET 127.0.0.1:8765/api/state` | ✅ 200（网络不受限，模型 API 照用） |

不用管理员、不用改 WebView2、xelatex / uv / babeldoc 照跑。

## 四、建议的落地方案（成本：1–2 天，风险低）

1. 起一个 **worker 进程**跑所有「模型工具调用 + 外部子进程」，令牌降成 Low IL；主进程（UI/HTTP）不动。
2. 安装/首次运行时把 `data/` 与每个项目目录标 Low（`icacls /setintegritylevel (OI)(CI)L`，幂等；
   新建项目时顺手标）。
3. 读写仍然过 `paths.resolve_allowed()` —— Low IL 管「写哪儿」，白名单管「读哪儿」，两层互补。
4. worker 侧再设 `PYTHONDONTWRITEBYTECODE=1`（Low 进程别去写 `__pycache__`）。

**口径**：做完之后可以对外说「文件写入由 Windows 内核限制在程序和你的项目目录里」；
但**读**仍是应用层白名单（Low IL 不拦读），SECURITY.md 里不要含糊。
