# 模型输出校验 · 升级方案（证据分 8 → 9）

**目标**：模型产出的**每一处可证伪的东西**（带单位的数值、页码、引号里的原文）在落盘/展示前都被机械核过一遍；核不过的不删、不改，标出来。
**架构**：新增一个纯函数模块 `verify.py`（无网络、无 LLM、确定性），在 5 个输出出口各挂 4-8 行。不改数据库、不加依赖、不改前端。
**现状**：入库侧已有硬闸门（`research_core.add_evidence` 校验页号 + 原文子串，带测试）；**输出侧零校验**（精读页码、正文数字、引用支撑全靠模型自觉）。

---

## 1. 「9 分」怎么算（可复核，不靠感觉）

| 指标 | 门槛 | 怎么测 |
|---|---|---|
| 伪造召回率 | ≥ 19/20 | `tests/test_verify.py` 对抗集：4 类产物 × 10 例（5 条注入伪造 + 5 条真值） |
| 误报率 | ≤ 1/20 | 同上，真值样本被标「待核」的比例 |
| 静默率 | 0 | 6 个输出出口（精读笔记 / 正文 / 框架 / 审查意见 / 引用台账 / 主对话作答）都要留下校验痕迹 |
| 确定性 | 2 次一致 | 纯函数，无 `temp`、无时间戳参与判定 |

达标后分项：精读 4→9、写作 4→9、主对话 3→8.5。**为什么主对话到不了 9**：聊天文本不是产物，只能脚注提示、不能阻断；要 9 得加「拿待核清单让模型重写一轮」（见 §7 的 B 档）。

---

## 2. 只核「能被原文证伪」的东西

不做语义判定（"这篇到底支不支持这个结论"），那是 9→10。只核三样：

1. **页码主张**：写了 `(p.7)` 的那一行，行里的带单位数值 / 引号原文必须真的在第 7 页。
2. **硬数值**：全文每个「数字 + 计量单位」（`120 mAh g⁻¹`、`0.94 eV`、`85%`）必须能在素材（证据表 + 精读笔记）里找到同族同值。
3. **引用锚句**：台账里带 `paper_id` + `cite_page` 的条目，锚句里的数值要在那一页上。

年份、章节号、图号、文献号**一律不核**——噪声率太高，误报会把这个功能做成噪音源。

## 4. 模块 `packages/workspace-service/verify.py`（已落地）

方案期的草稿代码已被对抗集改了三处，最终实现以仓库里的 `verify.py` 为准（约 150 行）：

1. `℃` 与 `°C` 必须在归一化时映射成同一个写法（原来 `700 ℃` 与 `700 °C` 对不上，误报）。
2. `qty_in_page` 从「字符串包含」升级成三层：归一原样命中 → 同单位族同值（吃 `0.120 mAh/g` 与 `0.12 mAh g⁻¹`）→ 计数/时长退回裸数字（中文「50 次」对不上西文 `50 cycles`）。
3. `audit(corpus="")` 语义等于「素材是空的」——每个数字都算没出处；`corpus=None` 才是「这次不核数值」。原来空语料直接跳过校验，等于给空库项目开绿灯。

导出接口：`quantities / qty_in_page / check_pages / check_quantities / audit / stamp / enabled`。
开关 `RW_VERIFY=enforce|shadow`：shadow 不落任何脚注，但每个 `audit()` 结果落一行 JSONL 到 `<data>/verify_shadow.jsonl`（`ts/label/page_claims/bad[]`），用来量真实误报率；enforce 不记账（结论已经在产物里）。

**单位族归一化**吃掉的写法差异：`mAh g⁻¹` / `mAh/g` / `mAh g-1`、`℃` / `°C`、`μm` / `um`、`−` / `–` / `-`、千分位与断行空格；数值比较留 0.5% 容差（`0.120` vs `0.12`）。

## 7. 主对话那 0.5 分：两档，默认 A

- **A（默认）**：脚注提示。零额外 latency，模型输出不动。评分 8.5。
- **B（开关 `RW_VERIFY=repair`）**：把待核清单发给模型重写一轮（"这些数字找不到出处，删掉或改成定性表述"），再核一次。评分 9，代价是这一步 latency ×2 且可能引入新错——所以默认关。

## 8. 天花板（写进注释，别假装没有）

1. **数值存在 ≠ 语义对口**：`0.94 eV` 在素材别处出现过就能通过。语义支撑（这篇到底支不支持这句话）机械判不了，是 9→10 的活。
2. **定性句不核**：没有数值、没有引号的主张（"显著优于"）落在 `page_skip`，只计数不判。
3. **扫描件/无文本层**：页码校验自动跳过（`stage_read` 本来就拒读这类）。
4. **单位族靠前缀表**：罕见单位（`Wh kg⁻¹`、`mA h g⁻¹`）会漏判成「未核」而不是「错」——错的方向安全。

## 9. 明确不做（YAGNI）

- 不加数据库表/字段：脚注就是状态，前端要标红就解析尾部那段。
- 不自动改写模型输出（除 B 档显式开启）。
- 不接第二个模型做语义复核（成本与不确定性都不划算；留给人工/审稿 agent）。
- 不动入库侧已有的 `add_evidence` 闸门（它是对的，`tests/test_research_core.py:25` 已锁）。
