# 社区技能安装

打开“设置 → Skill”，点击“安装技能”。软件自带 skills.sh、SkillHub 和 SkillsMP 三个技能源，首次使用即可搜索，无需另装 Node、Git 或技能管理器。

## 搜索并安装

1. 在“社区搜索”中输入至少两个字符，点击“搜索”。默认并行搜索全部已启用来源，也可以选择单个来源。
2. 点击结果中的“预览安装”，查看技能说明、SKILL.md 和附带文件数量。
3. 选择用户级或项目级安装范围。项目级安装需要项目已经设置文件夹。
4. 勾选需要的技能，点击“安装所选技能”。安装完成后显示实际保存路径。

安装流程不要求选择助手，也不会修改已有助手绑定。助手配置仍可在原有技能详情和专家启用矩阵中单独操作。

搜索结果会标注来源。如果某个来源无法访问，窗口会显示该来源的错误，并保留其他来源的搜索结果。

## 管理技能源

“设置 → Skill → 来源管理”与安装窗口中的“来源管理”打开同一个配置页面。

- 编辑来源的名称、网站地址、搜索接口、说明与启用状态。SkillHub 兼容来源还可编辑下载地址模板。
- 停用后，该来源退出全部来源搜索；启用后重新参与搜索。
- 删除后，来源配置保持删除状态，重启软件不会自动补回。已安装的技能、附带文件和助手配置保留。
- 添加来源支持标准技能索引 JSON，以及 skills.sh、SkillHub、SkillsMP 的兼容接口。
- “恢复内置来源”将三个内置来源恢复为默认配置，自定义来源会保留。

配置保存在当前软件的本机数据库中。名称、接口地址和启停状态会在保存后用于下一次搜索。

## 链接与本地导入

“链接 / 本地导入”支持：

- skills.sh、SkillHub 和 SkillsMP 的具体技能链接。
- GitHub 仓库、技能目录或 SKILL.md 链接，及 `owner/repo@skill` 写法。
- 本机技能目录、SKILL.md 文件，以及 ZIP、.skill、tar.gz 技能包。
- 提供标准技能发现索引的网站。

安装会保留完整技能目录，包括 scripts、references、assets 和二进制资源。导入只复制文件，不运行技能中的脚本。

用户级技能保存在 `~/.agents/skills`，项目级技能保存在项目的 `.agents/skills`。同名项目技能沿用已有的优先规则。

## 限制与失败处理

同一安装范围中已有同名技能时，安装会停止并保留现有文件。批量安装失败会撤销本次已经添加的文件和安装记录。

下载上限为 50 MiB，解压后上限为 100 MiB、5000 个文件。GitHub 链接通过仓库快照下载；超过上限的仓库，请先获取所需的单个技能目录或技能包，再从本地导入。下载源的登录要求、匿名配额和网络可用性由各社区决定，错误会直接显示在安装窗口中。

预览保留一小时，过期后需要重新读取。软件记录安装来源、文件数量、安装时间和文件校验值，技能详情中可以查看来源信息。
