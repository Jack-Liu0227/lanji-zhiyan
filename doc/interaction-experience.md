# 桌面交互更新

界面右上角提供「搜索命令」和「快捷键」入口。各页面标题栏下方常驻 To do 输入框。笔记、文件、项目、文献、进度和标签页支持右键菜单及「⋯」入口，菜单始终作用于触发它的对象。

## 常驻 To do

- 在顶部直接输入，按 Enter 或点「添加」保存；默认是个人待办，也可以选择具体项目。
- 点击「To do」展开清单，可搜索、按项目筛选、完成、重新打开、编辑或删除。勾选「已完成」查看完成的事项。
- 已保存待办存入本地数据库，重启后仍保留。未提交的草稿保存在本机浏览器，切页与刷新都不会清空；保存失败时保留原输入。
- 项目待办与「项目空间 → 进度与计划」共用数据；工作流绑定任务的完成状态由交付更新。

## 右键操作

| 对象 | 可用操作 |
| --- | --- |
| 笔记 / 文件夹 | 打开、打开所在位置、复制完整路径、记录相关待办，以及现有新建 / 删除操作 |
| 科研平台文件 / 格式转换文件 | 预览、打开所在位置、复制完整路径、记录相关待办 |
| 项目卡片 | 设为当前项目、打开项目文件夹、复制路径、新增项目待办、进入科研平台、删除 |
| Zotero 文献 | 打开 PDF、存为笔记、打开本地附件所在位置、复制附件路径 |
| 进度看板空白 / 状态列 | 创建进度任务、刷新；在某列创建时自动选中该列状态 |
| 进度任务卡片 | 编辑、完成 / 重新打开、移至前后状态、专家执行 / 验收（适用时）、新建、删除 |
| 科研流程阶段卡片 | 进入对应阶段、为该阶段创建待办 |
| 顶部待办清单 | 编辑、完成 / 重新打开、查看项目进度、新增、删除 |
| 标签页 | 关闭当前、关闭其他、关闭右侧 |

“打开所在位置”会打开该文件的父文件夹；文件夹本身则直接打开。不存在的路径会提示刷新，不会执行目标文件。

## 快捷键

| 操作 | Windows | 生效位置 |
| --- | --- | --- |
| 搜索命令与页面 | Ctrl+K | 全局，包括输入框 |

| 打开所在位置 | Alt+Shift+O | 焦点位于文件、笔记、项目等支持定位的条目 |
| 当前页搜索 | / | 有搜索框的页面，输入框外 |
| 保存笔记 | Ctrl+S | 可编辑的项目笔记 |
| 新建笔记 | Ctrl+Alt+N | 项目笔记，输入框外 |
| 加粗 / 斜体 | Ctrl+B / Ctrl+I | Markdown 编辑器 |
| 发送消息 | Ctrl+Enter | 对话输入框 |
| 前十个科研步骤 | Alt+1 … Alt+0 | 科研平台，输入框外 |
| 操作菜单 | Shift+F10 / 菜单键 | 焦点位于支持菜单的条目 |
| 菜单导航 | ↑ / ↓ / Home / End | 当前菜单 |
| 菜单执行 / 关闭 | Enter / 空格 / Esc | 当前菜单 |

macOS 的应用组合键使用 Command。帮助面板可以关闭应用快捷键，或单独关闭 `/`、`?`，偏好保存在本机。Tab、Esc、菜单与标签页的基本键盘操作始终可用。

## 行为约定

- 输入法组合输入期间保留原生编辑行为，不触发应用键盘处理。
- Esc 先处理当前菜单或最上层弹窗，关闭后恢复原焦点，不连带取消后台任务。
- 确认框的 Enter 执行当前聚焦按钮；删除操作默认聚焦取消。
- 右键菜单复用已有按钮动作及禁用状态；输入框保留原生编辑菜单。
- 侧栏、标签栏及命令导航从项目笔记离开前等待保存；保存失败保留编辑内容。
- 使用原生选择框，保留方向键、禁用选项与系统辅助技术支持。
- 统一可见焦点、状态通知语义和减少动态效果偏好；不拦截 Ctrl+F、Ctrl+T、Ctrl+W 等浏览器操作。

## 维护与验证

快捷键注册、帮助和菜单位于 `apps/desktop/web/views/interactions.js`；常驻待办位于 `global-todo.js`，进度操作位于 `kanban-view.js`。待办沿用现有 `/api/todos` 数据，文件位置通过 `/api/file/location` 解析并交给桌面宿主打开文件夹。

本次包含后端更新，源码运行环境需重启开发服务，然后刷新窗口；安装版需重新构建后才会包含这些变化。

行为回归：`python -m unittest tests.test_interactions_runtime -v`。测试使用临时数据库、临时项目与 Edge 浏览器；深浅主题和小窗口截图写入 `output/interaction-review/`。

待办 / 进度 / 文件定位回归：`python -m unittest tests.test_quick_todo_runtime tests.test_file_location tests.test_project_todos -v`。

完整检查：`python -m unittest discover -s tests -t .`、`node apps/desktop/web/ids.test.mjs`、`node apps/desktop/web/theme.test.mjs`。
