# 项目笔记分类与提示词模板

笔记默认包含五个一级分类：研究规划、文献研究、实验分析、写作投稿、提示词模板。“全部笔记”和“待整理”是辅助视图。二级分类默认留空，由用户按需要创建。

在 **项目空间 → 笔记 → 管理分类** 中新增、改名、调整上级、排序或删除分类。分类最多两级，删除时指定笔记去向，原文件不会被删除或移动。可以将当前分类方案设为以后新项目的默认方案，也可导出 `分类配置.json`；已有项目保持自己的配置。

笔记标题下可选择归属分类和标签。标签下拉支持搜索、多选、取消、清空，以及明确点击后创建新标签。勾选后弹层保持打开，点“完成”或按 Esc 收起。列表支持全文搜索和同时满足多个标签的筛选，勾选笔记后可批量归类或增减标签；“管理标签”可统一重命名和移除标签。

旧笔记仍在原路径。原“文献矩阵”“文献精读笔记”“文献综述”等目录映射到“文献研究”，并带对应初始标签；未知目录进入“待整理”。一旦用户主动清空或修改标签，旧目录映射不会再补回标签。需要文件目录操作时，可切换“按文件夹浏览”。

## 提示词模板

点击“新建模板”即可写入固定任务要求；无需定义变量。普通笔记可“复制为提示词模板”，副本拥有独立身份。仅给普通笔记加标签或移入模板分类，不会改变其类型。

需要参数时，在正文使用 `{{变量名}}`，例如：

```text
围绕 {{research_question}}，检查以下方面：{{focus}}。
给出证据、限制与下一步建议。
```

`project.title` 自动取项目名称，`project.question`、`research_question`、`研究问题` 自动取研究问题；应用时也可以填写覆盖值。其余变量在应用弹窗中填写。“模板设置”可以设置默认值、必填项、文本、数字、下拉选项或项目资料类型，以及可用、草稿、停用状态。

项目资料变量支持当前项目已登记的 Markdown、文本、CSV、JSON 文件。单份资料最多 200 KB，渲染后要求最多 250,000 字符；PDF 请先使用现有精读或文本提取流程生成相关资料。模板不会作为研究资料变量引用。

在笔记中点击“应用到 Agent”，或在已绑定项目的对话、工作流输入框中点击“提示词模板”。选择模板、填写变量、预览后应用。本轮请求会携带模板 ID、版本和变量；对话显示实际使用的模板版本。模板要求进入用户任务消息。

“默认绑定”支持项目、工作流步骤、助手、团队成员和日程。优先级是：本轮明确选择 → 日程 → 工作流步骤 → 团队成员 → 助手 → 项目。默认固定版本，勾选“跟随模板最新版本”后，新任务才会使用更新版本。“模板绑定”入口可查看和解除失效绑定。

任务排队时保存渲染快照，同一任务重试和恢复沿用原快照。模板修改或删除不会改变已经保存的任务要求；新的引用遇到缺失变量、停用或删除的模板会明确报错。模板笔记的“使用记录”可查看实际运行版本与渲染内容，单纯预览不计入使用记录。

Agent 可使用 `prompt_template_search`、`prompt_template_read`、`prompt_template_render` 查找、读取和渲染项目模板；只读运行可调用这些工具。模板从研究证据检索、默认团队材料和论证谱系中排除，产物通过 `used_template` 关系记录所用模板。

## 文件与服务

- 分类配置保存在项目的 `笔记/分类配置.json`；笔记元数据保存在 Markdown frontmatter 中，导出 Markdown 会保留分类、标签和模板定义。
- 新建笔记使用 UUID 文件名，显示标题独立保存。旧保存接口会保留新元数据，继续使用原有并发哈希和只读保护。
- 模板版本复用资产修订库，默认绑定保存在 `prompt_template_bindings`。项目删除时相应绑定一并清理。
- 功能随源码服务启动生效，已有运行实例需要重启服务并刷新页面。本次不包含安装包构建和发布。
